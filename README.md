# GBA IT Solutions - Website

This repository contains the initial structure and content for the GBA IT Solutions company website. The website provides information about the company's services, industry solutions, and contact details.

## Project Overview

GBA IT Solutions is an IT service provider for global clients. This website aims to present their offerings in a clear, modern, and professional manner.

The design philosophy loosely follows futuristic and user-centric principles, employing Tailwind CSS for styling.

## File Structure

The website is composed of several HTML files:

*   `index.html`: The main homepage.
*   `services.html`: An overview page for all service categories.
*   `managed-it-services.html`, `cloud-devops-services.html`, etc.: Detailed pages for each specific service (9 total).
*   `industry-solutions.html`: Information on solutions tailored to specific industries.
*   `about-us.html`: Company information, mission, vision, and values.
*   `contact.html`: Contact form and other ways to reach the company.
*   `privacy-policy.html`: Placeholder for the privacy policy.
*   `terms-of-service.html`: Placeholder for the terms of service.

All pages are styled using [Tailwind CSS](https://tailwindcss.com/) via its CDN.

## Running the Website

As the project currently uses the Tailwind CSS CDN and consists of static HTML files, no special build process is required.

To view the website:
1.  Clone this repository.
2.  Open any of the `.html` files (e.g., `index.html`) directly in a web browser.
